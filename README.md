# charkaLab

Веб-додаток для створення рецептів алкогольних напоїв. На стадії MVP — генератор
рецептів **мацератів** на основі ароматичних сполук сировини та бажаного профілю напою.

## Як це працює

1. Обираєте **основну сировину** (текстовий ввід з підказками по перших літерах).
2. Додаєте **допоміжну сировину** (до 10 рядків): форма (свіжа / суха / екстракт) та,
   за потреби, з кісточкою / без кісточки.
3. Обираєте **основу**: спирт пшеничний, спирт цукровий, вино червоне, вино біле.
4. Обираєте **бажаний профіль** напою: свіжий, хвойний, деревинний, цитрусовий тощо.
5. Натискаєте «Згенерувати» — додаток:
   - збирає ароматичні сполуки обраної сировини (залежно від форми/кісточки);
   - агрегує їх у профіль (окремо аромат і смак);
   - порівнює з бажаним профілем;
   - для непокритих характеристик шукає в базі додаткову сировину;
   - повертає кілька композицій з оцінкою збігу та поясненням.

## Стек

- Бекенд: Python + FastAPI + SQLAlchemy, база SQLite (`backend/`)
- Фронтенд: React + Vite + Tailwind (`frontend/`)
- Без авторизації/аутентифікації (за вимогами MVP)

## Запуск

### Бекенд

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

При першому старті база `backend/charkalab.db` створюється й наповнюється демо-даними.
Документація API: http://127.0.0.1:8000/docs

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Відкрийте http://127.0.0.1:5173. Запити `/api/*` проксіюються на бекенд (порт 8000).

## API

| Метод | Шлях | Опис |
|------|------|------|
| GET  | `/materials/suggest?q=` | Автодоповнення сировини по перших літерах |
| GET  | `/materials/{id}/forms` | Доступні форми/варіанти кісточки сировини |
| GET  | `/characteristics` | Список характеристик профілю |
| GET  | `/bases` | Список основ напою |
| POST | `/recipes/generate` | Генерація композицій під профіль |

## Модель даних

- `RawMaterial` — сировина (напр. калина), `has_pit_variants` — чи має варіанти з/без кісточки.
- `AromaCompound` — аромосполука (напр. лімонен), `kind`: `aroma` / `taste` / `both`.
- `Characteristic` — характеристика профілю (свіжий, цитрусовий…).
- `MaterialCompound` — концентрація сполуки в сировині для конкретної форми та кісточки
  (`form`, `pit`, `intensity`).
- `CompoundCharacteristic` — звʼязок сполуки з характеристикою (`weight`).
- `Base_` — основа напою.

## Наповнення бази реальними даними

Демо-дані задані структурою `SEED_DATA` у [backend/app/seed.py](backend/app/seed.py).
Та сама структура є форматом для імпорту. Щоб завантажити власні дані, можна викликати
`load_data(my_data)` з тим самим словником:

```python
{
  "characteristics": ["свіжий", "цитрусовий"],
  "bases": ["спирт пшеничний"],
  "compounds": [
    {"name": "лімонен", "kind": "aroma",
     "characteristics": {"свіжий": 1.0, "цитрусовий": 1.0}}
  ],
  "materials": [
    {"name": "калина", "has_pit_variants": true,
     "compounds": [
       {"compound": "лімонен", "form": "fresh", "pit": "na", "intensity": 0.8}
     ]}
  ]
}
```

- `form`: `fresh` | `dry` | `extract`
- `pit`: `with` | `without` | `na`

Завантаження ідемпотентне за іменами (повторний імпорт не дублює записи).
